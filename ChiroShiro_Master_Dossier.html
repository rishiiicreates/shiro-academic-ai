💡 Why WebFlux Netty Instead of Standard Tomcat or Python Gateway?
Standard synchronous servlet containers allocate 1 thread per active connection. During real-time LLM token generation (lasting 2 to 5 seconds per query), 100 concurrent students exhaust standard thread pools. Spring WebFlux leverages Project Reactor's event loop to multiplex 10,000+ concurrent student sessions across just 8 worker threads with less than 180MB RAM overhead.
Search & RAG Pipeline

Tri-Modal Hybrid Retrieval Engine

Pure semantic vector search fails when students ask for exact semester exam problems or full question papers. Shiro routes each prompt through three specialized retrieval lanes.

# Multi-Stage Docker Container Architecture
Stage 1 (Maven Build):
  FROM maven:3.9-eclipse-temurin-21 AS build
  RUN mvn clean package -DskipTests

Stage 2 (Runtime Container):
  FROM python:3.11-slim-bookworm
  RUN apt-get install -y default-jre-headless
  COPY --from=build target/chiroshiro-backend-1.0.0.jar app.jar
  COPY sidecar/ /app/sidecar/
  COPY data/ /app/data/
  ENTRYPOINT ["/app/docker-entrypoint.sh"]
